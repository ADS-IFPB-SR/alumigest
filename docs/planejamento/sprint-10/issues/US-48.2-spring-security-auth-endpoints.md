## 🎯 O que esta tarefa faz?

Configura o **Spring Security 6 stateless**, o filtro JWT e os endpoints públicos/privados de autenticação (`/api/v1/auth`), garantindo compatibilidade retroativa com as suítes MockMvc existentes no projeto.

---

## 📋 O que deve ser entregue?

- [ ] `SecurityConfig` stateless (`SessionCreationPolicy.STATELESS`), liberando `/api/v1/auth/login`, Swagger/Actuator públicos conforme perfil e exigindo autenticação em `/api/v1/**`.
- [ ] `JwtAuthenticationFilter` validando header `Authorization: Bearer <token>` e retornando JSON padronizado em `401 Unauthorized`.
- [ ] Endpoints `POST /api/v1/auth/login` e `GET /api/v1/auth/me` com DTOs imutáveis (`record`).
- [ ] Utilitário/configuração `@WithMockUser` de teste garantindo que os testes MockMvc legados dos demais módulos continuem verdes.

---

## ✅ Critérios de Aceitação

1. Login válido retorna HTTP 200 com token JWT e dados básicos do operador (`id`, `name`, `email`).
2. Credenciais inválidas ou requisições sem token retornam HTTP 401 com mensagem segura em português.
3. Toda a suíte `mvn test` do backend passa sem regressões.
