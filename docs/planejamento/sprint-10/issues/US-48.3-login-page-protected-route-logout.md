## 🎯 O que esta tarefa faz?

Implementa a experiência completa de login, sessão autenticada e logout no frontend React (`US-48`), bloqueando o acesso anônimo às rotas internas.

---

## 📋 O que deve ser entregue?

- [ ] Página `LoginPage.tsx` (`/login`) fiel aos tokens semânticos M3 (claro/escuro), sem links de auto-cadastro, com React Hook Form + Zod.
- [ ] `AuthContext` / `useAuth` e interceptor Axios injetando `Authorization: Bearer` e tratando `HTTP 401` com redirecionamento automático para `/login`.
- [ ] Componente `ProtectedRoute.tsx` envolvendo as rotas privadas em `App.tsx`.
- [ ] Exibição do nome real do operador autenticado na `Topbar.tsx` (removendo mock `"Admin / Gerente"`) e ação funcional no botão `Sair` da `Sidebar.tsx` limpando token e `QueryClient`.
- [ ] Testes unitários/integração Vitest cobrindo login, erro 401, rota protegida e logout.

---

## ✅ Critérios de Aceitação

1. Acesso não autenticado a qualquer rota interna redireciona imediatamente para `/login`.
2. Logout remove credenciais, limpa cache em memória e envia para `/login`.
3. Build TypeScript, Oxlint e Vitest 100% verdes.
