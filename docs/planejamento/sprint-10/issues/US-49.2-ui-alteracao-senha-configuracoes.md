## 🎯 O que esta tarefa faz?

Cria a seção/aba **"Segurança da Conta / Alterar Senha"** dentro de `/configuracoes` no frontend (`US-49`), conectada ao endpoint `PUT /api/v1/auth/password`.

---

## 📋 O que deve ser entregue?

- [ ] Componente `ChangePasswordCard.tsx` / aba em `/configuracoes` com React Hook Form + Zod (`Senha Atual`, `Nova Senha` $\ge 8$ caracteres, `Confirmar Nova Senha`).
- [ ] Botões acessíveis de mostrar/ocultar senha nos 3 campos.
- [ ] Tratamento de erro de senha atual incorreta sem derrubar a sessão ativa, reset do formulário no sucesso e notificação *toast*.
- [ ] Testes Vitest validando erros Zod, chamada de API e feedback visual.

---

## ✅ Critérios de Aceitação

1. Senhas divergentes, menores que 8 caracteres ou idênticas à atual bloqueiam o envio com erro claro por campo.
2. Alteração bem-sucedida limpa os inputs sensíveis e confirma via *toast*.
3. Build TypeScript, Oxlint e Vitest 100% verdes.
