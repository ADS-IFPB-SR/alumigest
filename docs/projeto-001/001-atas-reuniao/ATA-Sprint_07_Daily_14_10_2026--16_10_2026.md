* **Estabilização de Regras e Resolução de Bugs:**

  * Tratamento de sufixos malformados com fallback (BUG #434, PR #464).

  * Correções do BUG-039 (#436, PR #466) e BUG-040 (#437, PR #469).
  * Cobertura de testes preventivos para o caso reportado no BUG #443 (PR #468).
  * Prevenção de fechamento indevido do modal de cancelamento via Escape durante submissão (BUG-044 / #441).
