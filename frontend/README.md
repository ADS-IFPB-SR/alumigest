# 🌐 AlumiGest - Frontend

Interface Web responsiva e PWA (*Progressive Web App*) para gestão da vidraçaria e fábrica de esquadrias **Alumiportas**.

## 🛠️ Tecnologias
- **Linguagem:** TypeScript 5.x
- **Framework / Runtime:** Node.js 20 LTS + SPA Framework
- **Estilização:** CSS Moderno / Design System sob medida
- **Capacidades PWA:** Funcionamento offline para consultas rápidas na fábrica e responsividade para dispositivos móveis e desktops.
